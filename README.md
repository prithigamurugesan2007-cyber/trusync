# TruSync – AI-Powered Truth Detection Web Application

TruSync is an AI-powered web application designed to analyze user-provided content and provide truth-detection results through an easy-to-use interface.

## 🚀 Features

- AI-powered content analysis
- User-friendly and responsive interface
- Frontend and backend integration
- API-based request processing
- Displays analysis results clearly
- Simple and intuitive user experience

## 🛠️ Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

⚙️ How It Works
User enters or submits content for analysis.
The frontend sends the request to the backend through an API.
The backend processes the request.
The analysis result is returned to the frontend.
The result is displayed to the user in a simple and understandable format.
🎯 Project Objective

The main objective of TruSync is to provide a simple web-based platform for analyzing content using AI-powered functionality while demonstrating practical knowledge of frontend development, backend development, and API integration.
